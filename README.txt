# Наші Мальви — онлайн-гра для двох

## Вміст
- `index.html` — готовий вебзастосунок, підключений до Firebase `nashi-malvy`.
- `firestore.rules` — правила доступу Firestore. Не замінюйте їх правилом `allow read, write: if true`.

## Порядок
1. Firebase Console → Firestore Database → Rules → Edit rules. Замінити вміст текстом `firestore.rules`, натиснути Publish. До публікації перевірити правила в Rules Playground або Emulator; не відкривати базу для всіх.
2. Для публікації на Firebase Hosting потрібен Firebase CLI. У Google Cloud Shell або на комп'ютері: `npm install -g firebase-tools`, `firebase login`, `firebase init hosting` (вибрати існуючий проєкт `nashi-malvy`, public directory `public`, без перезапису index.html), покласти `index.html` у `public/index.html`, `firebase deploy --only hosting`.
3. Відкрити адресу, яку поверне Firebase Hosting, на двох телефонах. Творець створює кімнату й надсилає код другому учаснику.

## Обмеження
- Цей код і правила не були протестовані на живому Firebase-проєкті. Перевірте правила до використання особистих відповідей.
- Код кімнати є секретним запрошенням: не публікуйте його. Перший анонімний користувач із кодом може зайняти вільне друге місце.
- Анонімний обліковий запис може втратитися після очищення даних браузера; повернення до старої кімнати тоді неможливе без іншого методу входу.
- Зміна картки залишає старі відповіді в базі, але вони не показуються в новому раунді.
- Правила для двох користувачів не є наскрізним шифруванням.
